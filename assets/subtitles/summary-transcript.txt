08 / 00:02:09.417 / Read both. In a deliberate order.

去噪期间两份记忆都只读；未写入的状态不贡献动态增量。

Each action block first reads the demonstration intent.
Progress then refines that reference-conditioned action representation.
The action representation changes, not the reference memory.
Both states are read-only during denoising; an unwritten state adds zero delta.

SOURCE NOTE: Serial reads, not parallel memory mixing. Both fast states are read-only during action denoising.
