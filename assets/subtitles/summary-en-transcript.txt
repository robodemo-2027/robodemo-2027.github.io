A human demonstration contains more than a goal. It shows a procedure: how to approach an object, coordinate movement, and complete a task.

But a robot does not follow exactly the same path. It also needs to remember what actually happened during its own execution.

The reference video builds a persistent demonstration-intent memory. Semantic and motion features capture what the procedure means and how it unfolds. A second memory tracks interaction progress using robot observations, states, and actions that have already been executed. Each action block reads intent first, then progress.

On Imitator Game, the Full50 checkpoint reaches eighty-four point six percent success across two thousand episodes.

We also evaluate RoboDemo on real household manipulation: organizing a tabletop, arranging sofa cushions, and pouring from a bottle into a cup. Across these three tasks, the model achieves a mean success rate of seventy-three point three percent. Here are excerpts from the recorded robot executions.

The same memory separation is useful when the environment changes. These recordings show tabletop organization under altered lighting, a different background, and a new scene.

When a human video is unavailable, Refreward ranks robot demonstrations using the task instruction and the initial image. The selected procedure enters the same intent-memory interface.
