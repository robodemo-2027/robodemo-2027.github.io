00:00:08.000 / 01 / MOTIVATION / A demonstration specifies a procedure
A human demonstration shows a procedure, not just a final goal.

00:00:15.100 / 01 / MOTIVATION / Intended progress is not realized progress
The reference shows what should happen. It cannot tell us what the robot has actually completed. We preserve the procedure in one memory, and track completed interactions in another.

00:00:28.100 / 02 / METHOD / Encode the reference. Write the intent once.
Hierarchical sampling combines sparse global and event frames with a dense motion clip. Frozen semantic and motion encoders produce fused memory tokens. These write Retrieval T T T once, before rollout.

00:00:44.100 / 02 / METHOD / Update memory after each completed interaction
The execution branch encodes the new image, conditioned on the current robot state and the preceding executed action. It updates progress memory causally, without overwriting the reference.

00:00:58.100 / 02 / METHOD / Cross-Memorization with cascaded reads
Context tokens write to fast weights. Action-side queries read them. Inside each action block, the expert reads intent first, then refines that representation with actual progress. Both memory states remain fixed during action denoising.

00:01:16.100 / 02 / METHOD / Optional input: a retrieved robot demonstration
When a human video is unavailable, Refreward ranks robot demonstrations using the instruction and initial image. The selected video enters the same intent-memory interface.
